## About This Portfolio

Personal portfolio built with **React + Vite**, showcasing 3 deployed production projects across computer vision, LLM applications, and full-stack MERN development. Features GSAP animations, glassmorphism UI, and full mobile responsiveness.

> AI/ML Engineer and Full-Stack Developer with hands-on experience building and shipping production-grade systems. ## Featured Projects

### 🧠 MRI Brain Tumor Detection with Gesture Control
> CNN + ResNet18 · FastAPI · OpenCV · TensorFlow · Render · Netlify

Multi-class MRI brain tumor classifier achieving **94% accuracy** on 4,000+ scans. Deployed FastAPI inference server with **sub-300ms latency**. Integrated OpenCV gesture controls for touchless zoom, pan, and scan navigation — eliminating manual mouse interaction during diagnosis review.

[![Live Demo](https://img.shields.io/badge/Live_Demo-brain--tumor--with--gesture.netlify.app-00C7B7?style=flat-square&logo=netlify&logoColor=white)](https://brain-tumor-with-gesture.netlify.app/)
[![GitHub](https://img.shields.io/badge/GitHub-Source_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/ARTiwary/MRI-brain-tumour-detection-with-gesture-control-)

### 🍽️ Smart Dining Assistant — Zara (LLM-Powered)
> Next.js · Node.js · PostgreSQL · ChromaDB · Groq API · Docker · Vercel

QR-per-table self-ordering system powered by **Zara** — an in-house AI assistant built on Groq API + ChromaDB RAG pipeline. Handles menu Q&A in **English, Hinglish, and Telugu** without staff intervention, reducing order-taking time by **~40%**. Admin dashboard includes real-time order lifecycle management and daily revenue analytics.

[![Live Demo](https://img.shields.io/badge/Live_Demo-smart--dinning--assistent.vercel.app-000000?style=flat-square&logo=vercel&logoColor=white)](https://smart-dinning-assistent.vercel.app/)

### 🖐️ Air Gesture Recognition System
> React.js · Node.js · Express.js · OpenCV · REST API · Netlify

Real-time gesture-controlled image transfer across browser tabs using a touchless **"Grab & Drop"** interaction model. Low-latency REST API backend with in-memory caching, reducing manual drag-and-drop effort by **~60%**.

## Run Locally

```bash
# Clone the repo
git clone https://github.com/ARTiwary/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
